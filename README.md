# Cyber Runner – วิ่ง คิด ตอบ พิชิตโลกคอมพิวเตอร์

เกม 2D Educational Platformer สำหรับกิจกรรมแข่งขันวันวิทยาศาสตร์ของโรงเรียน
กลุ่มเป้าหมาย **ป.4 – ม.3** — วิ่ง กระโดด เก็บเหรียญ และตอบคำถามคอมพิวเตอร์ 15 ด่าน
ภายในเวลาแข่งขันที่ครูกำหนด

| | |
|---|---|
| เทคโนโลยี | HTML5 + CSS3 + JavaScript ES6+ (Canvas 2D, Web Audio API) |
| Backend | Google Sheets ผ่าน Apps Script (รายชื่อ + คะแนนพัฒนาการ) |
| จำนวนด่าน | 15 ด่าน (ด่าน 15 = COMPUTER BOSS) |
| คลังคำถาม | 138 ข้อ แยกตามด่าน / ระดับความยาก |
| เบราว์เซอร์ | Google Chrome (แนะนำ), Edge, Firefox |

## 1. เริ่มเล่นเร็วที่สุด

### วิธี A — เปิดไฟล์ตรง ๆ (ง่ายสุด ไม่ต้องติดตั้งอะไร)

ดับเบิลคลิก **`index.html`** → เล่นได้ทันที

เกมออกแบบให้ทำงานบน `file://` ได้ โดยอ่านข้อมูลจาก `data/data-bundle.js`
(ไฟล์สำรองที่รวม JSON ทั้งหมดไว้) เพราะ Chrome ไม่อนุญาตให้ `fetch()` ไฟล์ JSON
จากเครื่องโดยตรง

> ถ้าคุณ **แก้ไฟล์ JSON ใน `data/`** แล้วเปิดแบบ `file://`
> ต้องสร้าง bundle ใหม่ก่อน (ดูหัวข้อ 6) ไม่งั้นเกมจะยังใช้ข้อมูลเดิม

### วิธี B — เปิดผ่าน Local Server (แนะนำสำหรับตอนพัฒนา)

เลือกวิธีใดก็ได้:

```bash
# Python (มีติดมากับ Windows/macOS ส่วนใหญ่)
python -m http.server 8000

# Node.js
npx serve .
```

แล้วเปิด <http://localhost:8000>

หรือใช้ **VS Code + ส่วนขยาย Live Server** → คลิกขวาที่ `index.html` → *Open with Live Server*

เมื่อเปิดผ่าน server เกมจะอ่าน `data/*.json` โดยตรง แก้ไฟล์แล้วรีเฟรชเห็นผลทันที

## 2. วิธีเล่น

### การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| `←` `→` หรือ `A` `D` | เดิน / วิ่ง |
| `Space` `↑` `W` | กระโดด (กด 2 ครั้ง = กระโดดคู่) |
| `Shift` | วิ่งเร็ว |
| `Esc` หรือ `P` | หยุดชั่วคราว |
| `R` | กลับไปจุดเช็คพอยต์ |
| `H` | ขอคำใบ้ (ถ้าครูเปิดใช้งาน) |

บนจอสัมผัส/โน้ตบุ๊กแบบทัชสกรีน เปิด **"แสดงปุ่มควบคุมบนหน้าจอ"** ในหน้าตั้งค่าได้

### กติกา

1. วิ่งไปทางขวาจนถึง **ประตูคำถาม (QUESTION GATE)**
2. คำถามจะปรากฏด้านบนจอ พร้อมป้ายคำตอบ **A / B / C / D** ลอยเรียงกันอยู่เหนือทางวิ่ง
3. วิ่งลอดใต้ป้ายเพื่ออ่านตัวเลือกให้ครบ แล้วไปยืนบนแผ่นเรืองแสงใต้ป้ายที่คิดว่าถูก
   จากนั้น **กระโดดชนป้าย** เพื่อตอบ (ป้ายอยู่สูงกว่าหัวผู้เล่นเล็กน้อย
   จึงไม่มีการชนโดยไม่ได้ตั้งใจระหว่างวิ่ง)
4. **ตอบถูก** → `CORRECT!` + คะแนน + เปิดกำแพงให้ไปต่อ
5. **ตอบผิด** → แสดงเฉลย + คำอธิบาย + หักคะแนน แต่ **ไม่ตาย ไม่ Game Over** และเดินต่อได้
6. เก็บ **เหรียญข้อมูล ◆** เพื่อคะแนนเพิ่ม
7. ทำคะแนนให้มากที่สุดก่อนหมดเวลา

**ด่าน 15 – COMPUTER BOSS:** ตอบถูกแต่ละข้อ = ทำลายพลังชีวิตบอส 1 หน่วย
ตอบผิดบอสจะเยาะเย้ยแต่ไม่ทำอันตรายผู้เล่น ตอบถูกครบ = ชนะเกม + โบนัสพิเศษ

## 4. การเพิ่ม Asset (Drag & Drop Workflow)

เกมนี้ **เล่นได้ทันทีโดยไม่มีไฟล์ Asset เลย** เพราะทุกภาพและเสียงมี
*Procedural Placeholder* วาด/สังเคราะห์ด้วยโค้ดไว้แล้ว
เมื่อคุณใส่ไฟล์จริง เกมจะใช้ไฟล์นั้นแทนอัตโนมัติ

### ขั้นตอน

1. ดาวน์โหลด Asset 2D ที่มี License เหมาะสม (ดูหัวข้อ 7)
2. วางไฟล์ลงในโฟลเดอร์ `assets/` ตามหมวดหมู่
3. เปิด **`src/config/assets.js`** แล้วตรวจว่า key ตรงกับชื่อไฟล์ของคุณ
4. รีเฟรชหน้าเว็บ — เสร็จ

ชื่อไฟล์ที่เกม "รอ" อยู่ในแต่ละโฟลเดอร์ ดูได้จากไฟล์ `.gitkeep` ในโฟลเดอร์นั้น
ถ้าใช้ชื่อไฟล์เดิม **ไม่ต้องแก้โค้ดเลยแม้แต่บรรทัดเดียว**

### ตัวอย่าง: เปลี่ยนตัวละครเป็นภาพนิ่ง

```javascript
// src/config/assets.js
const ASSETS = {
  player: 'assets/characters/my-robot.png',   // ← เปลี่ยนแค่บรรทัดนี้
  ...
};
```

### ตัวอย่าง: เปลี่ยนตัวละครเป็น Sprite Sheet

สมมติมีไฟล์ `assets/characters/hero-run.png` เป็นชีตแนวนอน 8 เฟรม เฟรมละ 48×48 px

```javascript
// src/config/assets.js
const SPRITES = {
  playerRun: {
    src: 'assets/characters/hero-run.png',
    frameWidth: 48,     // ความกว้าง 1 เฟรม (px)
    frameHeight: 48,    // ความสูง 1 เฟรม (px)
    frames: 8,          // จำนวนเฟรม
    speed: 14,          // เฟรมต่อวินาที
    loop: true,         // เล่นวนซ้ำ
    row: 0              // ถ้าชีตมีหลายแถว: แถวที่ใช้ (เริ่มจาก 0)
  },
  ...
};
```

แอนิเมชันของผู้เล่นที่เกมใช้: `playerIdle`, `playerRun`, `playerJump`,
`playerFall`, `playerCorrect`, `playerWrong`
ใส่เฉพาะบางตัวก็ได้ — ตัวที่ไม่มีไฟล์จะกลับไปใช้ placeholder แทน

### ฉากหลังของแต่ละโลก

| ธีม | ด่าน | key ใน `assets.js` |
|---|---|---|
| Computer World | 1–3 | `bgComputer` |
| Cyber / Logic World | 4–6 | `bgCyber` |
| Coding World | 7–9 | `bgCoding` |
| Network / Digital World | 10–12 | `bgNetwork` |
| AI / Future World | 13–14 | `bgAI` |
| Boss Arena | 15 | `bgBoss` |

### เสียงและเพลง

วางไฟล์ใน `assets/sounds/` และ `assets/music/` ตามชื่อใน `assets.js`
ถ้าไม่มีไฟล์ SoundManager จะสังเคราะห์เสียง 8-bit ให้เอง — เกมไม่ error

รูปแบบที่รองรับ: **PNG, JPG, WEBP, SVG, GIF** (ภาพ) / **WAV, MP3, OGG** (เสียง)

> เปิดแบบ `file://` เบราว์เซอร์บางตัวอาจบล็อกการโหลดไฟล์ในโฟลเดอร์ย่อย
> ถ้าใส่ Asset แล้วไม่ขึ้น ให้เปิดผ่าน Local Server (วิธี B)

## 5. โหมดครู / ผู้ดูแล (Admin Settings)

กดปุ่ม **⚙ ตั้งค่า** ที่หน้าแรก ปรับได้ทั้งหมดโดยไม่ต้องแก้โค้ด:

| กลุ่ม | ปรับได้ |
|---|---|
| เวลา | 10 / 15 / 20 / 30 นาที หรือกรอกเอง |
| คะแนน | ตอบถูก, ตอบผิด, ผ่านด่าน, เก็บเหรียญ, ภารกิจพิเศษ, Combo Bonus |
| คะแนนติดลบ | อนุญาต / ไม่อนุญาต (ค่าเริ่มต้น: คะแนนต่ำสุด = 0) |
| ด่าน | จำนวนด่านที่เปิดใช้งาน (1–15), จำนวนคำถามต่อด่าน |
| ความยาก | EASY / NORMAL / HARD / AUTO (เลือกตามชั้นของผู้เล่น) |
| เสียง | เปิด-ปิดเสียงเอฟเฟกต์และเพลง + ระดับเสียง |
| การเรียนรู้ | เปิด-ปิดคำใบ้ (Hint) |
| การเข้าถึง | ขนาด UI, โหมด Contrast สูง, ปุ่มควบคุมบนหน้าจอ |
| ข้อมูล | ล้างกระดานคะแนน |

กด **SAVE SETTINGS** แล้วค่าจะถูกเก็บใน LocalStorage ของเครื่องนั้น

### ค่าเริ่มต้นของคะแนน

| เหตุการณ์ | คะแนน |
|---|---|
| ตอบถูก | +100 |
| ตอบผิด | −50 |
| ผ่านด่าน | +100 |
| เก็บเหรียญ | +10 |
| ภารกิจพิเศษ / ชนะบอส | +200 |
| ตอบถูกต่อเนื่อง | +25 ต่อสเต็ปคอมโบ |

### ระดับความยากกับชั้นเรียน (โหมด AUTO)

- **ป.4 – ป.6** → EASY / NORMAL
- **ม.1 – ม.3** → NORMAL / HARD

### การแจ้งเตือนเวลา

เหลือ **5 นาที / 3 นาที / 1 นาที** → แจ้งเตือนบนจอ
เหลือ **30 วินาที** → เสียงเตือน
เหลือ **10 วินาที** → นับถอยหลังตัวใหญ่
ทั้งหมดนี้ **ไม่หยุดเกม** ผู้เล่นเล่นต่อได้ตลอด

## 6. การแก้ไขคำถามและด่าน

### เพิ่ม / แก้คำถาม

แก้ไฟล์ `data/questions.json` โครงสร้างต่อข้อ:

```json
{
  "id": "q001",
  "level": 1,
  "question": "อุปกรณ์ใดทำหน้าที่ประมวลผลข้อมูล?",
  "options": ["RAM", "CPU", "Monitor", "Keyboard"],
  "correctAnswer": 1,
  "explanation": "CPU ทำหน้าที่ประมวลผลคำสั่งและข้อมูลของคอมพิวเตอร์",
  "difficulty": "easy",
  "category": "hardware",
  "hint": "ชื่อย่อมาจาก Central Processing Unit"
}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `id` | รหัสไม่ซ้ำ |
| `level` | ด่านที่ใช้คำถามนี้ (1–15) |
| `options` | ตัวเลือก 4 ข้อ |
| `correctAnswer` | ลำดับของคำตอบที่ถูก เริ่มนับจาก **0** |
| `explanation` | คำอธิบายที่แสดงหลังตอบ (**จำเป็น** — เป็นหัวใจของการเรียนรู้) |
| `difficulty` | `easy` / `normal` / `hard` |
| `category` | หมวด เช่น `hardware`, `internet`, `security`, `logic`, `ai` |
| `image` | (ไม่บังคับ) path รูปประกอบคำถาม |
| `hint` | (ไม่บังคับ) คำใบ้เมื่อกด `H` |

ระบบจะสุ่มคำถามและ **สลับตำแหน่งตัวเลือก** ทุกครั้ง และไม่ถามข้อเดิมซ้ำในรอบเดียวกัน

### แก้ด่าน

`data/levels.json` กำหนดชื่อ ธีม ความยาว และ `seed` ของแต่ละด่าน
`seed` เดียวกันจะสร้างแผนที่หน้าตาเหมือนกันทุกครั้ง — **ผู้แข่งขันทุกคนจึงเจอด่านเหมือนกัน**
เปลี่ยน `seed` ถ้าต้องการแผนผังใหม่ และเพิ่ม `segments` ถ้าต้องการด่านที่ยาวขึ้น

### สร้าง data-bundle ใหม่ (จำเป็นเมื่อจะเปิดแบบ `file://`)

```bash
node tools/bundle-data.mjs
```

สคริปต์จะอ่าน `data/*.json` แล้วเขียน `data/data-bundle.js` ให้ใหม่
ถ้าคุณเปิดเกมผ่าน Local Server เท่านั้น ก็ไม่จำเป็นต้องรันคำสั่งนี้

## 8. Art Direction

## 9. กระดานคะแนนและการตัดสิน

คะแนนบันทึกใน LocalStorage ของเครื่องที่ใช้แข่ง เก็บ:
ชื่อผู้เล่น, ชั้น, ห้อง, ทีม, คะแนน, เวลาที่ใช้, จำนวนด่านที่ผ่าน, ตอบถูก, ตอบผิด, เหรียญ, คอมโบสูงสุด, วันที่แข่ง

เรียงจากคะแนนสูงไปต่ำ **กรณีคะแนนเท่ากัน** ตัดสินตามลำดับ:

1. ใช้เวลาน้อยกว่า
2. ตอบถูกมากกว่า
3. ผ่านด่านมากกว่า

อันดับท้ายเกม: **S / A / B / C / D** คำนวณจากคะแนน ความแม่นยำ และจำนวนด่านที่ผ่าน

> กระดานคะแนนในเกมยังเก็บในเครื่องไว้สำรองเสมอ
> ถ้าเชื่อม Google Sheets แล้ว คะแนนจะถูกส่งขึ้นระบบกลางอัตโนมัติ และดูได้ที่หน้า **Dashboard ครู**

## 11. อัปโหลดเว็บ + ระบบ Dashboard (Google Sheets)

ระบบนี้แยกเป็น 2 ส่วนที่ต้องตั้งค่าคนละที่:

1. **GitHub Pages** — โฮสต์เกมและหน้า Dashboard ให้เปิดจากอินเทอร์เน็ตได้
2. **Google Apps Script** — เก็บรายชื่อนักเรียนและผลการเล่นใน Google Sheet

เกมยังเล่นได้แม้เน็ตล่ม: คะแนนถูกบันทึกในเครื่องก่อน แล้วค่อยส่งขึ้นชีตเมื่อเน็ตกลับมา

### ขั้นที่ 1 — สร้าง Google Sheet และวาง Apps Script

1. เปิด [Google Sheets](https://sheets.google.com) แล้วสร้างชีตใหม่ ตั้งชื่อเช่น `Cyber Runner 2569`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิม แล้ววางทั้งหมดจากไฟล์ `tools/google-apps-script.gs`
4. แก้ `SECRET_KEY` ให้เป็นข้อความที่เดายาก (จำไว้ จะใช้ในขั้นถัดไป)
5. กดบันทึก แล้วกด **Deploy → New deployment**
   - ชนิด: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**  ← สำคัญมาก ไม่งั้นเกมส่งคะแนนไม่ได้
6. กด Deploy แล้วอนุญาตสิทธิ์ตามที่ Google ถาม
7. **คัดลอก Web app URL** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

ในชีตจะมีเมนู **Cyber Runner → สร้างตารางเริ่มต้น** เพื่อสร้างชีต `Students` และ `Results`

> ถ้าแก้โค้ด Apps Script ภายหลัง ต้องกด **Deploy → Manage deployments → ดินสอ → New version** ไม่งั้นระบบยังใช้เวอร์ชันเก่า

### ขั้นที่ 2 — ใส่ URL ลงในเกม

เปิดไฟล์ `src/config/cloud.js` แล้วแก้ 2 ค่า:

```javascript
ENDPOINT: 'https://script.google.com/macros/s/ใส่-URL-ที่คัดลอกมา/exec',
TEACHER_KEY: 'รหัสเดียวกับ SECRET_KEY ใน Apps Script',
```

### ขั้นที่ 3 — อัปโหลดขึ้น GitHub Pages

1. สร้างบัญชี GitHub (ถ้ายังไม่มี) ที่ https://github.com
2. กด **New repository** ตั้งชื่อเช่น `cyber-runner` เลือก **Public** อย่าติ๊ก Add README
3. ในโฟลเดอร์เกม เปิด Terminal แล้วรัน:

```bash
git init
git add .
git commit -m "Cyber Runner วันวิทยาศาสตร์"
git branch -M main
git remote add origin https://github.com/ชื่อคุณ/cyber-runner.git
git push -u origin main
```

4. บน GitHub เข้า repo → **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/** (root)
   - กด Save
5. รอ 1–2 นาที แล้วเปิด

`https://ชื่อคุณ.github.io/cyber-runner/`

หน้า Dashboard ครูอยู่ที่

`https://ชื่อคุณ.github.io/cyber-runner/dashboard.html`

### ขั้นที่ 4 — เพิ่มรายชื่อนักเรียน

เปิดหน้า Dashboard → กรอกชื่อ ชั้น ห้อง แล้วกด **เพิ่มรายชื่อ**
หรือวางหลายบรรทัดเช่น:

```
สมชาย ใจดี,ป.5,1
สมหญิง เก่งมาก,ม.1,2
```

นักเรียนเปิดเกมแล้ว **เลือกชื่อตัวเองจากรายการ** ก่อนเริ่มเล่น
เมื่อจบเกม คะแนนจะถูกส่งเข้าชีต และแสดงใน Dashboard เป็นกราฟพัฒนาการ (คะแนนแต่ละครั้งที่เล่น)

### ถ้ายังไม่อัป GitHub

เปิด `dashboard.html` ผ่าน Local Server ก็ใช้ได้เหมือนกัน ตราบใดที่ใส่ `ENDPOINT` แล้ว

## 12. ติดตั้งลงเครื่องอื่น (Setup)

ไม่ต้องลง Python หรือโปรแกรมอื่น ใช้ได้บน Windows 10/11

### วิธีเร็วสุด — USB

1. ที่เครื่องต้นฉบับ ดับเบิลคลิก **`สร้างไฟล์พกพา.bat`**
2. จะได้โฟลเดอร์ **`CyberRunner-USB`** บนเดสก์ท็อป
3. Copy ทั้งโฟลเดอร์ใส่ USB
4. ที่เครื่องใหม่ เปิดโฟลเดอร์นั้น แล้วดับเบิลคลิก **`ติดตั้ง.bat`** หรือ **`install.bat`**
5. รอจนขึ้นข้อความติดตั้งเสร็จ จะมีไอคอน **Cyber Runner** บนเดสก์ท็อป

คะแนนจากทุกเครื่องไปที่ Google Sheet ชุดเดียวกัน (ต้องต่อเน็ตตอนส่งคะแนน)

### Linux

1. Copy โฟลเดอร์เกมหรือ `CyberRunner-USB` ไปเครื่อง Linux
2. เปิดเทอร์มินัลในโฟลเดอร์นั้น แล้วรัน:

```bash
chmod +x install.sh play.sh
./install.sh
```

จะได้ไอคอน **Cyber Runner** บนเดสก์ท็อปและในเมนูแอป  
ถ้าอยากเปิดโดยไม่ติดตั้ง ให้รัน `./play.sh`

ใช้ `python3` ที่มากับ Linux ส่วนใหญ่ ไม่ต้องลงอะไรเพิ่ม

### อยากได้ไฟล์ Setup.exe แบบเกมทั่วไป

ติดตั้ง [Inno Setup](https://jrsoftware.org/isinfo.php) แล้วเปิดไฟล์ `tools/CyberRunner.iss` กด Build จะได้ `CyberRunner-Setup.exe` นำไปลงเครื่องอื่นเหมือนโปรแกรมทั่วไป

## 10. หมายเหตุสำหรับผู้พัฒนาต่อ

- ทุกโมดูลอยู่ใน namespace เดียวคือ `window.CR` (ไม่ใช้ bundler ไม่ต้อง build)
- ลำดับการโหลดสคริปต์กำหนดไว้ใน `index.html` — ถ้าเพิ่มไฟล์ใหม่ ให้เพิ่ม `<script>` ตามลำดับ dependency
- โลกของเกมสูงคงที่ **720 หน่วย** และขยายตามความกว้างจอ ทำให้ทุกเครื่องเห็นพื้นที่เล่นเท่ากันในแนวตั้ง
- `CR.game` เข้าถึงได้จาก Console เพื่อดีบัก เช่น `CR.game.loadLevel(14)` เพื่อกระโดดไปด่านบอส
- ถ้าแก้ตำแหน่งป้ายคำตอบหรือค่าฟิสิกส์การกระโดด ให้รัน `node tools/check-question-zone.mjs`
  เพื่อตรวจว่ายังวิ่งผ่านโซนได้โดยไม่เผลอชนป้าย กระโดดถึงทุกป้าย และข้ามกำแพงกั้นไม่ได้
- เป้าหมายประสิทธิภาพ 60 FPS: game loop ใช้ delta time แบบมีเพดาน และ preload asset ก่อนเริ่มเกม
